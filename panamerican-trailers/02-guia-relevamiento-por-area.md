# PANAMERICAN TRAILERS — Guía de Relevamiento por Área (v1)

> Herramienta de trabajo para las entrevistas con cada gerente/responsable.
> Objetivo: entender **cómo fluye la información hoy**, **qué herramientas usan**,
> **dónde vive cada dato** y **dónde se rompe el flujo**, antes de automatizar.
> Acompaña al documento `01-mapa-flujo-informacion.md`.

---

## 0. Cómo usar esta guía

**Método recomendado por área (1.5 a 2 horas por sesión):**

1. **Entrevista** con el responsable usando el *Bloque Universal* (sección 1) +
   las preguntas específicas del área.
2. **Observación** en sitio: pedir que muestren en pantalla cómo hacen 1 caso real
   de principio a fin (no que lo cuenten, que lo *hagan*).
3. **Recolección de evidencia**: pedir copia de cada formato/Excel/plantilla que usan
   (ver checklist sección 11).
4. **Validación cruzada**: lo que un área dice que "entrega" debe coincidir con lo
   que la siguiente dice que "recibe". Las diferencias = puntos a arreglar.

**Regla de oro de la entrevista:** por cada dato importante, preguntar siempre las
mismas 4 cosas → *¿De dónde viene? ¿Dónde lo guardas? ¿A quién se lo pasas? ¿Cómo
se lo pasas (sistema/Excel/correo/WhatsApp/papel)?*

## 1. Bloque Universal (aplica a TODAS las áreas)

### 1.1 Propósito y personas
- ¿Cuál es la misión del área en una frase? ¿De qué eres responsable y de qué NO?
- Organigrama del área: roles, cuántas personas, quién decide qué.
- ¿Qué pasa cuando la persona clave de un proceso falta (vacaciones/enfermedad)?

### 1.2 Entradas (lo que reciben)
- ¿Qué información necesitas para empezar a trabajar y de quién la recibes?
- ¿En qué formato y por qué canal te llega? (sistema / Excel / correo / WhatsApp / papel / verbal)
- ¿Qué tan completa y confiable llega? ¿Qué te falta seguido y a quién se lo pides?
- ¿Cuánto esperas en promedio por esa información antes de poder avanzar?

### 1.3 Proceso (lo que hacen)
- Lista los pasos de tu proceso principal, de inicio a fin (que lo describan paso a paso).
- ¿Qué decisiones/aprobaciones hay en el camino y quién las da?
- ¿Qué pasos son manuales y se podrían evitar? ¿Qué reescribes o copias de un lado a otro?
- ¿Qué excepciones o casos especiales rompen el proceso normal? ¿Cada cuánto pasan?

### 1.4 Salidas (lo que entregan)
- ¿Qué produces y a quién se lo entregas? (otra área / cliente / proveedor / gerencia)
- ¿En qué formato y por qué canal lo entregas?
- ¿Cómo sabe el que recibe que ya está listo? ¿Hay confirmación o se asume?
- ¿Qué pasa si entregas algo con error? ¿Cómo se detecta y cuánto cuesta corregirlo?

### 1.5 Herramientas y dónde vive el dato
- Lista TODOS los sistemas/programas que usas (nombre exacto y versión si aplica).
- ¿Cuál es el sistema "oficial" y cuáles son Excel/archivos paralelos "no oficiales"?
- ¿Dónde se guardan los archivos? (PC local / carpeta compartida / nube / correo)
- ¿Quién tiene acceso? ¿Hay respaldos? ¿Qué pasa si se pierde ese archivo?
- ¿Los sistemas usan el **mismo código de cliente / proyecto** que las demás áreas? ¿O cada uno el suyo?

### 1.6 Volumen, tiempos y medición
- ¿Cuántos casos manejas por semana/mes? ¿Picos de temporada?
- ¿Cuánto dura tu proceso de punta a punta (mínimo, promedio, peor caso)?
- ¿Qué mides hoy? ¿Qué reportas a gerencia, cada cuánto y cómo lo armas?

### 1.7 Dolores y handoffs (lo más importante)
- ¿Cuáles son tus 3 mayores frustraciones con la información que recibes/entregas?
- ¿Con qué área tienes más fricción y por qué?
- Si pudieras pedir UN cambio mágico para tu trabajo, ¿cuál sería?
- ¿Qué información te gustaría tener y hoy no tienes (o tienes tarde)?

## 2. Comercial / Ventas

- ¿Cómo entra un lead? (referido, web, feria, contacto directo) ¿Dónde se registra?
- ¿Cómo se levanta la **especificación** del food trailer/contenedor? ¿Hay un formato? ¿Quién lo llena?
- ¿En qué momento exacto un lead pasa de "prospecto" a "oportunidad" a "proyecto en firme"? ¿Quién autoriza cada salto?
- Para cotizar: ¿de dónde sacas el **costo estimado** y el **tiempo de fabricación**? ¿Lo pides a Producción/Ingeniería o lo estimas tú?
- ¿Cuántas versiones de cotización suele tener un proyecto? ¿Cómo controlas la versión vigente?
- ¿Cómo manejas los **cambios de especificación** que pide el cliente después de cotizar/cerrar? ¿A quién avisas y cómo?
- ¿Qué define el cierre? (contrato firmado, anticipo recibido) ¿Cómo se lo comunicas a Producción, Compras y Finanzas?
- ¿Llevas pipeline/embudo? ¿Dónde? ¿Cómo sabe gerencia cuánto hay por cerrar?
- Postventa: ¿quién atiende reclamos/garantías del cliente y cómo se registra?
- Exportación: ¿qué datos del cliente extranjero necesitas y quién los usa después (Finanzas/Logística)?

---

## 3. Diseño / Ingeniería

> Validar primero: ¿es un área formal o vive dentro de Producción/Ventas? ¿Quién hace este rol?

- ¿Quién convierte la especificación de venta en **diseño y planos**? ¿Con qué software (AutoCAD, SolidWorks, etc.)?
- ¿Cómo se genera la **lista de materiales (BOM)**? ¿En Excel, en el ERP, a mano? ¿Quién la valida?
- ¿La BOM incluye cantidades, especificaciones de acero inox, componentes importados, consumibles?
- ¿Cómo le pasas la BOM a Compras y la ruta de fabricación a Producción? ¿Mismo documento o cada uno por su lado?
- ¿Reutilizan diseños de proyectos anteriores o cada uno arranca de cero? ¿Hay biblioteca de diseños?
- ¿Cómo se controla la **versión** del diseño cuando el cliente pide cambios? ¿Cómo se entera Compras/Producción del cambio?
- ¿Quién define el **costo objetivo** del proyecto y cómo se compara luego contra el real?

---

## 4. Compras / Importación

- ¿Cómo recibes lo que hay que comprar? (BOM, requisición, correo, verbal) ¿Quién lo autoriza?
- ¿Tienes maestro de **proveedores**? ¿Dónde? ¿Compras locales vs. importadas, qué % cada una?
- Ciclo de importación paso a paso: cotización proveedor → OC → pago → embarque → aduana → recepción. ¿Cuánto dura cada etapa?
- ¿Dónde se atasca más seguido la importación? (proveedor, naviera, aduana, pago, agente)
- ¿Cómo registras el **costo real** del material (incluyendo flete, aduana, impuestos)? ¿Quién lo necesita después?
- ¿Llevas **inventario** de materiales? ¿En qué sistema? ¿Es confiable vs. lo físico?
- ¿Cómo sabe Producción que el material para su proyecto ya llegó? ¿Cómo le avisas?
- ¿Qué pasa cuando Producción necesita algo urgente que no está? ¿Compra de emergencia?
- ¿Asocias cada compra a un **proyecto** o se compra "al montón"? ¿Cómo separas material por proyecto?
- ¿Cómo coordinas con Finanzas los pagos a proveedores y anticipos de importación?

---

## 5. Producción

- ¿Cómo recibes la orden de fabricación? ¿Qué información trae y qué te falta seguido?
- Etapas de fabricación (corte, soldadura inox, ensamble, acabado, etc.): ¿quién hace qué y cómo se pasa el trabajo entre etapas?
- ¿Cómo se **programa** la producción? (qué proyecto va primero) ¿Quién decide la prioridad?
- ¿Cómo registras el **avance** de cada proyecto? (% , fotos, parte diario, nada) ¿Dónde?
- ¿Cómo registras el **consumo real de material** y las **horas-hombre** por proyecto? ¿O no se registra?
- Control de calidad: ¿quién revisa, con qué checklist, qué pasa con una no conformidad?
- ¿Cómo manejas un **cambio de especificación** que llega con el proyecto ya empezado?
- ¿Qué información le das a Ventas para que actualice al cliente sobre su pedido?
- ¿Cómo declaras "producto terminado" y se lo pasas a Logística/Exportación?
- ¿Qué necesitas de RRHH (personal, turnos) y cómo lo pides?

---

## 6. Finanzas / Contabilidad / Admin

- ¿Cuál es el **ERP/sistema contable exacto** (nombre y versión)? ¿Qué módulos usan y cuáles no?
- ¿El ERP permite **costear por proyecto** (ingresos vs. costos de ese proyecto)? ¿Lo usan así?
- ¿Cómo se factura? (anticipo, hitos, contra entrega, exportación) ¿Quién dispara la factura y con qué información?
- ¿Cómo entra a Finanzas el costo real de materiales (Compras), mano de obra (RRHH) y logística?
- Cobranza: ¿cómo se le da seguimiento? ¿Cómo sabe Ventas/Gerencia qué está por cobrar?
- Pagos a proveedores e importaciones: ¿cómo se priorizan? ¿Quién aprueba?
- Flujo de caja: ¿cómo se proyecta hoy? ¿Con qué anticipación se ve un problema de liquidez?
- Exportación: ¿qué documentos financieros genera (factura comercial, etc.) y quién los necesita?
- ¿Qué reportes le entregas al CEO, cada cuánto y cuánto trabajo manual te cuesta armarlos?
- ¿Qué datos de otras áreas recibes tarde, incompletos o no cuadran al cerrar el mes?

---

## 7. Recursos Humanos

- ¿Cómo se registra **asistencia y horas** del personal de planta? (reloj, papel, Excel)
- ¿Se asignan horas-hombre a un **proyecto** específico? (clave para saber el costo real de mano de obra)
- ¿Cómo se calcula la **nómina** y con qué sistema? ¿Se conecta con Finanzas o se reescribe?
- ¿Cómo se gestionan los requerimientos de personal de Producción (contratar, turnos extra)?
- Capacitación/certificaciones (ej. soldadores inox): ¿se controla? ¿dónde?
- Rotación/ausentismo: ¿se mide? ¿afecta los tiempos de los proyectos?
- ¿Qué información de RRHH necesita Finanzas y Producción, y cómo se las entregas hoy?

---

## 8. Servicio al Cliente / Postventa

> Crítico en una empresa exportadora: el cliente está lejos, los problemas se
> resuelven a distancia y la reputación viaja por reseñas y recomendaciones.

- ¿Cómo entra una solicitud del cliente? (correo, WhatsApp, teléfono, formulario web, ticket) ¿Dónde se registra?
- ¿Qué tipos de solicitudes manejas? (consulta de estado, reclamo, garantía, repuesto, soporte técnico, capacitación) ¿% aproximado de cada uno?
- ¿Cómo atiendes clientes en el extranjero? (idioma, zona horaria, soporte remoto, viajes técnicos)
- ¿Cuál es tu SLA de respuesta y de resolución? ¿Se mide o solo se siente?
- Cuando una solicitud requiere a otra área (Producción, Ingeniería, Ventas, Repuestos), ¿cómo escalas y cómo sabes que efectivamente se atendió?
- **Garantía:** ¿qué cubre, por cuánto tiempo, cómo se documenta el alcance al cerrar la venta? ¿El cliente recibe constancia escrita?
- En un **reclamo de garantía**: ¿cómo se diagnostica a distancia (fotos, video, manual)? ¿Quién decide si procede? ¿Cómo se cubren los costos (envío de repuesto, viaje técnico)?
- **Repuestos:** ¿existe catálogo? ¿Cómo se cotiza, factura y envía al exterior? ¿Hay stock o se manda fabricar?
- ¿Hay un canal formal para que los **reclamos recurrentes** (defectos que se repiten) lleguen de vuelta a Producción/Ingeniería y se corrija el diseño/proceso? (loop de mejora)
- ¿Cómo se mide la satisfacción del cliente? (encuestas, reseñas, NPS, nada)
- ¿Qué herramienta usas para gestionar tickets/solicitudes? (helpdesk, CRM, Excel, solo correo)
- Cuando un cliente llama, ¿qué información del proyecto necesitas tener a la mano (specs, planos, lote, fecha de entrega, garantía vigente)? ¿La tienes fácil o la buscas?

---

## 9. Logística / Exportación

> En una empresa exportadora, es donde el proyecto "se convierte en dinero
> entregado". Un error aquí cuesta multas, demoras y reclamos del cliente final.

- ¿Cómo te enteras de que un proyecto está listo para embarcar? ¿Quién te avisa y con cuánta antelación?
- ¿Qué documentos de exportación preparas? (factura comercial, packing list, certificado de origen, BL/AWB, certificado sanitario si aplica) ¿Quién los genera y quién los firma?
- ¿Qué **Incoterm** se usa por defecto (FOB, CIF, DAP, etc.)? ¿Varía por cliente/destino?
- ¿Cómo se elige al agente de carga / forwarder / naviera? ¿Hay maestro de proveedores logísticos?
- ¿Cómo se coordinan los tiempos: fecha disponible en planta vs. fecha de booking/zarpe?
- ¿Qué pasa si el producto no llega a tiempo al puerto? (booking perdido, multas, reprogramación)
- **Empaque para exportación:** ¿cómo se prepara? (madera tratada IPPC, trincado dentro del contenedor, flat-rack si excede medidas, fumigación) ¿Quién lo hace, planta o un tercero?
- **Aduana de exportación:** ¿cómo se gestiona? ¿Hay agente aduanal? ¿Cuánto tarda?
- **Seguros de carga:** ¿quién los contrata y cómo se documentan?
- ¿Cómo se hace el **tracking** del embarque y cómo se informa al cliente la fecha estimada de llegada?
- ¿Cómo entra el **costo real de logística** (flete, seguro, agente, aduana) a Finanzas para cerrar el costo del proyecto?
- **Daños o incidentes en tránsito:** ¿con qué frecuencia? ¿Cómo se reclama al seguro o naviera?
- ¿Qué herramienta/sistema usas? (Excel, módulo del ERP, plataforma de la naviera, correo)

---

## 10. Gerencia / CEO (entrevista contigo + el CEO)

- ¿Cuáles son los **5 números** que el CEO quiere ver TODOS los días? ¿Y semanal/mensual?
- ¿Qué decisión importante se ha tomado tarde o mal por falta de información?
- ¿Cuál es la prioridad del negocio este año (crecer, exportar más, márgenes, ordenar)?
- ¿Cómo se sabe hoy si un proyecto fue rentable? ¿Cuánto después de entregarlo?
- ¿Qué reportes recibe hoy, quién los arma, y confía en esos números?
- ¿Cuál es la restricción real del negocio: vender más, producir más rápido, capital de trabajo?

## 14. Matriz de Handoffs (consolidar al final del relevamiento)

> Se llena cruzando lo que cada área DICE que entrega vs. lo que la siguiente DICE
> que recibe. Cada desajuste detectado = oportunidad concreta de automatización.

| Ingeniería → Compras | BOM | | | |
| Ingeniería → Producción | Planos/ruta | | | |
| Compras → Producción | Materiales/avisos | | | |
| Producción → Ventas | Avance del pedido | | | |
| Producción → Logística | Aviso de producto terminado | | | |
| Ventas → Logística | Cliente, Incoterm, destino | | | |
| Logística → Finanzas | Documentos de export. y costos logísticos | | | |
| Ventas → Servicio al Cliente | Garantía, specs, datos del cliente | | | |
