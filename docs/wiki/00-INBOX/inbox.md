# 📥 INBOX — Raw Input

> Todo lo que entra sin procesar. El agente diario lo convierte en notas estructuradas.

---

## Cómo usar el Inbox

1. **Deposita aquí cualquier cosa**: idea de voz, link, texto, imagen, conversación de Claude
2. **El agente diario** lee todo lo del inbox, extrae lo importante y lo convierte en markdown estructurado
3. **El archivo procesado** se mueve al dominio correcto (01-08)
4. **El inbox se limpia** — queda vacío para el día siguiente
